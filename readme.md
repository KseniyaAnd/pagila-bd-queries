# Pagila SQL Queries

This project contains SQL queries written using the [Pagila demo database](https://github.com/devrimgunduz/pagila).

## Tasks

The project includes 7 SQL queries:

1. Count the number of movies in each category, sorted in descending order.
2. Find the top 10 actors whose movies were rented the most.
3. Find the movie category that generated the highest rental revenue.
4. Find movies that are not present in the inventory without using the `IN` operator.
5. Find the top 3 actors who appeared in the most movies in the **Children** category, including ties.
6. Count active and inactive customers in each city, sorted by the number of inactive customers in descending order.
7. Find the category with the highest total rental duration for movies whose titles start with **A**, and for cities whose names contain a hyphen (`-`), using a single query.

## Technologies

- SQL
- PostgreSQL
- Pagila demo database

## Project Structure

All 7 SQL queries are stored in a single file.


## Getting Started

1. Install PostgreSQL.
2. Download and set up the [Pagila demo database](https://github.com/devrimgunduz/pagila).
3. Connect to the database.
4. Open `queries.sql` and execute the queries.
